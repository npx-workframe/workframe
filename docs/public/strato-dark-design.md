# Strato Dark migration

The Workframe-owned `strato-dark` stylesheet was retired on 2026-07-22 when Architectonic became the canonical theme source.

Persisted `strato-dark` preferences migrate to `liquid-glass-dark`, which preserves the dark translucent surface family without retaining a second palette implementation. See [the current UI design-system contract](design.md).
