# Neo Blue migration

The Workframe-owned `neo-blue` stylesheet was retired on 2026-07-22. Persisted preferences migrate to Architectonic `neo-dark`; Blueprint remains available as a separate line-based technical identity.

This avoids conflating color identity with relief geometry. See [the current UI design-system contract](design.md).
